# 桌面植物 B：离线语音与嘴部表达

按 HCI 桌面植物“拟人说话”要求，为现有 B 画圈的 Awaken 效果补充实际音频资源。台词沿用现有英文字幕 `A little light helps me grow.`，属于虚构植物表达；不是湿度传感或真实植物状态判断。英文字幕和语音一致，中文表达与更自然的声音仍需后续完善。

## 实现与资源

`PlantDialogue.wav` 为本机 Windows System.Speech 的 Microsoft Zira Desktop 语音合成输出，台词由项目提供；未下载第三方录音、未训练声音或调用付费服务。不把生成音频宣称为 Microsoft 授权素材包或 CC0 录音。来源、采样率和文件摘要见 voice-provenance.json。

音频是约 2.57 秒、22050 Hz 的单声道 PCM，113348 字节。复用 actor 原有一个空间 AudioSource。B 进入实际效果阶段后播放；重复 B 重启同一资源，不叠加语音实例。仅初始化时读取 PCM 并计算约 50 Hz 响度包络，运行时读取包络驱动已有嘴部；播放结束恢复闭嘴。没有逐帧 GetData、文件写入或新建音源。嘴部动画保持盆和追踪锚点不变。

Undo、D 清除、Reset、追踪丢失、禁用和应用暂停会停止语音并清理引用；暂停同时取消尚在施法前摇的协程，避免暂停后又开始说话。Undo 恢复拟人状态时不会自动重播旧台词。原字幕仍可见，完成一句话后嘴部不会继续无声地周期张合。
