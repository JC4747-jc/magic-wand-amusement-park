# 四季树：共用火机手势驱动的本地候选

目标仍为魔法乐园的 YOLO 实物检测 → 定位/选择 → 共用火机手势 → 对象魔法。此轮只修正四季树效果，不将自然树替代打人柳。

| 维度 | 修改及编辑器证据 |
| --- | --- |
| A 捏合松开 | 可逆树冠分层着色，保持季节；树干保留原材质，未声称整个资产完成动漫重制 |
| B 单指画圈 | 树干表面两眼、瞳孔和嘴；逐帧实测眨眼幅度，保存面部近景 |
| C 张掌横挥 | 夏、秋、冬、春循环；秋季橙色、冬季稀疏树冠、春季恢复 |
| D 握拳张开 | 有界阵风与季节落叶反馈；枝条运动后回到静止，不弹出打人柳宝箱 |

HciSeasonTreeChecks 打开实际 ParkTree，使用明确标注的虚拟目标和合成手部样本，经生产 ProcessHandSample 入口判定；开放手势先解除选择/UI 的输入占用，随后与火机 TabletopGestureRules 比对，逐次只触发一次。采样驱动在游戏 Update 中运行，动画期间持续供样，未放宽生产超时保护。另检验撤销、锚点/尺寸不变及动画中途 Reset。9 张图片为 Unity 实际渲染，含原始、风格化、拟人、四季、阵风和面部近景。

回归：原树网格 121000/121000 叶片顶点参与形变，树干/锚点固定、非法风向恢复及生长/撤销通过；六类内容的 24 条共用手势轨迹与 UI/尺寸/平面抢占、追踪过期/丢失、远距检查通过；四种实验条件的 96 次动作尝试、139 条结果通过。详见三个结果子目录和 mesh-result.txt。

视觉检查：自然与分层树冠可区分；秋季与冬季树冠变化可见；面部贴在树干且可辨认。整树视角下面部较小，头显视距下的可读性仍需验收；叶片细密与秋季饱和度仍属待评审美术，不宣称达到用户最终审美目标。

失败证据保留：早期 fixture 压缩供样造成动画取消；Editor 更新与游戏更新不同步；基准规则未扣除选择后的张手准备帧。最终修正测试供样及准备逻辑，不关闭生产仲裁、冷却或追踪失效保护。较早失败输出是历史诊断，不是最终结果。

资源：Unity 重任务串行，工作线程 1，沿用有界日志/内存/磁盘守卫。四个通过任务中 5 秒采样最低可用内存 6.372 GiB，最大单任务主机磁盘增长 1.47 MiB；这些是主机采样值，不是连续峰值或硬件健康保证。未启动训练或下载。

边界：本轮未做真实 YOLO、XR 关节、PICO 双眼或 Android 构建；未发布这批运行时代码。打人柳及其他对象的 HCI 效果缺口继续保留。六类入口检查不能视为八用例全部完成。源文件哈希记录于 sources.json；主工作区 index 未修改。
