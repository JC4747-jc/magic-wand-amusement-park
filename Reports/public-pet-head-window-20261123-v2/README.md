# 萌宠自动头位双目复测

固定当前真实 YOLOv8n 狗回包和已校准双目输入，比较原生 2–120 像素全宽搜索、身体深度限定的搜索，以及左右眼各自输出鼻尖与双眼关键点后，在预测附近做双向局部纹理匹配。全宽搜索的 57 个对照与原探针逐项一致。无可用输入的帧计入时序并中断连续确认。

## 结果

- 身体限定搜索找回犬第 34 帧，但第 33 帧纹理仍有歧义，第 35 帧触及新边界。第 136 帧出现右图错配，离人工鼻尖约 18 像素，该帧未通过双目头部几何门控。两种限定形式均无连续三帧确认。
- 左右图的鼻眼几何加双向局部纹理，使犬第 32–35 帧同一 YOLO ID 连续四帧通过。逐帧鼻尖视差为 45、48、50、53 像素，人工标注为 45、47、50、55 像素。预测右鼻尖离人工标注约 0–2.9 像素。两次确认的候选深度约 2.56 和 2.41 米。鼻尖旁的 LiDAR 样本不足，狗头距离仍缺独立测距。
- 独立弗赖堡回放中，人工身体框的 12 帧不可见头部样本和默认 YOLO 的同一批 12 帧均无通过。两组分别有 8 和 5 帧具备可比较输入。人工身体框的可见帧有 3 次连续确认输出。默认 YOLO 的 5 帧可见样本中只有 1 帧具备可比较输入，未形成确认。
- 同一只公制橘猫的候选检测可取得两段连续确认，候选鼻尖深度 1.461 和 1.908 米，LiDAR 在左图预测鼻尖处为 1.537 和 2.044 米。默认 YOLO 的公制猫组仍无连续确认。身体限定法在该候选猫有更多通过帧，尚不足以更换正式门控。

## 范围

犬鼻尖标注取自人工检查的像素裁切，裁切位置借助已有模型输出定位。第 32–35 帧只有一个犬个体，弗赖堡样本具备独立可见性标签且无公制深度。本轮复用已保存的 PICF 与模型关键点结果，在独立探针中复验匹配。生产运行时仍需验证正式输入上的右目关键点供给、稳定头位接入、真实手势和 PICO。Unity 场景与 Android 包无需因本轮诊断重建。

有界运行最低采样可用内存约 8.37 GiB，任务进程组最高采样约 275 MiB，报告目录在运行期间最高采样约 365 KiB。资源保护未触发。
