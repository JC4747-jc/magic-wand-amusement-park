# 虫类 · 复杂背景与小目标训练增量

新增 22 张可直接训练的照片，包括 10 张蜘蛛、8 张蟑螂、4 张衣鱼或盲蛛负例。逐张查看了标注图，其中 2 只蜘蛛和 2 只蟑螂在 640×480 训练图上的标注宽度小于 64 px。样本包含墙缝、叶片遮挡、针织表面、暗墙和手指旁的虫体。照片中的重叠实例无法可靠确认时保留为待审，本轮排除 1 张。

- 保留 96 张原训练图，追加后为 118 张训练图。16 张原开发验证 JPEG 和标签的哈希逐一一致。合并目录含 41 个蟑螂目标、44 个蜘蛛目标、33 张训练负例。
- 样本来自 iNaturalist 的 CC0 照片。使用 36 个既有索引和 233 张可读原始照片核对来源与重复，对独立留出逐条核对摄影者、观察页、照片 ID、文件和像素哈希。感知指纹距离不大于 5 的候选在采集时排除。[iNaturalist 照片接口](https://www.inaturalist.org/api) · [来源、授权与审核框](../../TrainingData/bugs-inat-training-context-20261123.json)
- 数据包包含 22 对 JPEG 与 YOLO 标签、来源清单。负例附空标签。已检查每个框与 YOLO 坐标格式的转换、压缩包 CRC 及内容哈希。完整训练目录本地实测 8,562,402 字节，采集网络传输 17.72 MiB。[训练增量](reviewed-training-increment.zip) · [哈希与验收范围](verification.json)
