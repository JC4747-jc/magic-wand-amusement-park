# 虫类 · 独立公开照片 PICF 复核

使用 `mr/jc@90928aef` 的 PC 识别服务，依次复测蟑螂 v16 与双类视觉提示候选。每个候选收到 76 条 PICF v2 回包，其中 1 条预热、15 条整帧、60 条裁窗。逐包校验场景、帧号、时间戳、长宽、权重哈希和类别。照片经桌面回放，PICO、真实距离和 Unity 手势未在本轮测试。生产 `bugs.weights` 仍为空。

## 结果

| 候选与类别 | 整帧 TP / FP / FN | 四窗 TP / FP / FN |
|---|---:|---:|
| v16 · Cockroach | 2 / 0 / 3 | 4 / 0 / 1 |
| 视觉提示 · Cockroach | 0 / 1 / 5 | 0 / 0 / 5 |
| 视觉提示 · Spider | 1 / 1 / 5 | 1 / 0 / 5 |

- v16 四窗新增命中玻璃杯内 *Blatta orientalis* 与木板上的 *Ischnoptera deropeltiformis*（全图宽 62 px）。铝箔场景的 *Ectobius pallidus* 仍漏检，同种另一张整帧已命中。纹理布上的蟑螂四窗 IoU 从整帧的 0.909 降至 0.521。[蟑螂对照](cockroaches.jpg)
- 双类候选在两种输入中均只命中同一张 *Argiope trifasciata*。整帧将 1 张家蛛认成蟑螂、1 张衣鱼认成蜘蛛，四窗中两处误报消失。v16 只开放蟑螂类别，蜘蛛照片用于检查误报。[蜘蛛与相似负例](spiders-and-lookalike.jpg)
- v16 整帧与四窗的回包中位耗时分别为 206.37 ms 与 1,073.09 ms。双类候选分别为 105.49 ms 与 545.20 ms。四窗值为同一照片四次回包耗时之和，未含裁切、合并及 Unity 端耗时。[逐图结果](result.json)

## 样本与门槛

冻结了 6 张蜘蛛、5 张蟑螂和 4 张相似负例。所有照片有 CC0 授权和来源记录，16 张原始照片经旧标注索引的 ID、URL、像素哈希和感知哈希查重。一张多只蟑螂重叠的照片在推理前排除；玻璃杯下沿另有一个辨认不清的节肢动物，预先划为忽略区，两种模式均无落入忽略区的计分框。蜘蛛包括一张宽 53 px 的低照弱目标。样本用于误差定位，覆盖范围不足以估计实际环境中的检出率。[冻结协议与每张照片来源](frozen-input.json)

整帧 JPEG 为 640×480，四个固定窗为 384×384。只合并同类且 IoU ≥ .50 的框。匹配按同类 IoU ≥ .50。v16 回包和计分阈值均为 .65，双类候选回包阈值为 .399、计分阈值为 .50。完整原始回包与裁窗坐标已保存。[v16 回包](v16-wire.jsonl) · [视觉提示回包](visual-wire.jsonl)

本地通过 `Tools/run_public_room_plant_bounded.ps1 -RunId public-bugs-independent-photos-20261123-v2 -BugIndependentHoldout` 执行，复用原候选权重及冻结 JPEG。首轮在请求前即因读取场景枚举位置错误退出，改从保存版本的 `scene_protocol` 读取后完成；协议文件 SHA256 始终为 `d14e66a6fe083405be07e5e142d5b33c37fae12f49119d34dc13158b607ff613`。执行脚本 SHA256 为 `69a92ed8136f867b898e66d81b0718d92bf7a08a47b58cb7d03a7fe641c19f15`。本轮最低采样可用 RAM 7.54 GiB，进程组 RSS 最高采样 983 MiB，最大阶段采样输出约 245 KiB，资源保护未触发。[资源采样](resources.json)

下个开发里程碑是复用既有双类训练入口，补带背景、遮挡和小尺寸的蜘蛛训练正例与易混淆负例，并补蟑螂跨种训练。公开留出照片保持封存，另用真实 PICO 画面验证跟踪、触发和延迟后再决定是否启用权重。
