# HCI 历史石像 D：荷花许愿树（2026-11-16）

本批将 D 的一圈扁球占位替换为可展开的荷花与带签牌的许愿树。延续统一链路：YOLO 识别目标 → 定位/选择 → 火机共用手势规则 → 对象效果。没有新增石像专属手势；平面确认仅为效果位置的辅助输入。

## 实现

- 六朵三层荷花、带缺口莲叶、花蕊、渐细树枝、单片树叶和七个悬挂许愿签。自有程序化网格，无外部资产下载或生成模型训练。
- 全部花朵共用网格，树干/叶片合并网格，签牌共用网格；总计三个唯一网格、一个自有材质、十四个渲染器。唯一顶点/三角形统计见 geometry 文件，不能与六朵实例合计绘制量混淆。
- 花瓣通过顶点着色器在闭合与展开形态之间插值，树木逐渐长出，签牌随时间轻摆；没有逐帧生成网格或写磁盘。
- 效果定位于已确认水平锚点，独立于实物根节点和尺寸标定。无碰撞体阻挡选择射线。Undo 收回效果，Stop 渐退，Reset、无效平面与目标丢失清除；销毁时释放自有网格与材质。

## 验证

- Unity 6000.0.33f1，已保存 ParkStatue 场景，大理石和青铜两变体。合成 A/D 关节输入通过生产 ProcessHandSample，逐帧与火机 TabletopGestureRules 对比，单次触发且接受。
- 检查未确认平面时拒绝 D、非有限平面拒绝、展开中间态/完成态、A 外观不被 D 覆盖、撤销、停止（含展开途中）、复位、平面失效和追踪丢失；检查锚点/标定不变、网格/材质复用、签牌摆动和零运行时/着色器错误。
- 六条 Park 线路的 24 条共用手势轨迹与实验条件矩阵（96 次尝试、139 条结果）回归通过。CSV 为合成测试，不是被试数据。
- 八张 Unity 相机渲染包含展开中、完成、荷花细节与复位；人工检查。灰色背景为隔离审查背景，青色小块为虚拟定位辅助。并非头显透视截图。
- 首轮测试脚本枚举名称错误、等待时间未覆盖施法前奏，以及复位后未重新标定的测试假设已修正；保留本地失败日志，不把失败结果算作通过。

## 验收边界

手动平面是合成测试输入，不等于房间重建、真实地面检测或遮挡正确。本批只交付 D 的本地模型/动画与共用手势接入；B 完整伸懒腰、C 真实历史/语音、其他用例差异、真实 YOLO/PICO 闭环及移动端性能仍待完成。Goal 保持 active。

本批未生成新 APK。已发布 hci-unified-validation-20261116 不包含宠物描边、石像卡通或本次荷花许愿树。真实 PICO 双眼渲染、帧率、锚点与遮挡需要接头显验证。
