# 树木场景 · 标定双目距离复核

用 [Miti360 原作者的标定双目照片](https://huggingface.co/datasets/DeKUT-DSAIL/miti360) 复核 18 组不同拍摄帧，共 28 个检测框和人工标注框。固定原始灰度图、相机内参、约 12.9 cm 的基线与相机坐标约定。原生 C# 匹配器和接收器门槛从 GitHub `mr/jc@c750e39` 取出编译。ParkTree 交互范围为 0.20–3.00 米。扩大匹配块做双向校验，计算前景标注内的视差分布。距离来自标定图像匹配，精度未用激光测距验证。人工标注仅用于评估。[原生匹配与前景深度](result.json) · [独立九组与宽匹配块对照](../public-tree-miti360-depth-confirmation-20261123/result.json)

三带 C# 回退未增加真实检测框的可靠定位。宽匹配块恢复两个实拍中人工标注框的近距估计，约 2.32 和 2.66 米，本轮这两张图没有合格检测框。宽匹配块在确认组的边界样本只有两个区域支持同一距离，保留原门槛和正式配置。约 5.65 米的远树和约 30 米的背景框均被候选拒绝。目检了两组样本的双目对应图，本地图片 SHA256 `9a4008d90c4085cfac8df0aa4b0bfe07feac09ace4ebda11967b02dbe42ee870`。
