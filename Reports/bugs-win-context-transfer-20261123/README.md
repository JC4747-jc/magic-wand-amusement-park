# 虫类 · 双类训练和独立 PICF 结果

使用 `mr/jc@cb6cade` 冻结的 118 张训练图、16 张开发验证图，以本机 YOLO11n COCO 权重初始化双类检测头。旧实验训练 20 轮后在有效门槛下仍无正确框，本轮改用新的初始化与两张图一批。全程离线，CUDA 单进程、0 个加载子进程、20 轮、AdamW、初始学习率 .0005。共跑 1,180 批，首个可训练卷积记录 1,172 次优化器更新，已确认参数改变。原 15 张独立照片在训练完成后才进入推理。[冻结方案](../../TrainingData/bugs-inat-context-transfer-plan-20261123.json) · [训练记录](training.json) · [逐轮指标](epochs.csv)

## 独立照片

用与上一轮相同的 PC 识别源码和输入，校验 76 条 PICF v2 回包。共 1 次预热、15 次整帧、60 次固定裁窗。整帧和四窗在 .399 回包门槛均无候选框，在 .50 计分门槛下为蟑螂 0/5、蜘蛛 0/6。CPU 整帧回包中位 33.57 ms，四窗累计回包中位 166.70 ms。速度是在未返回框的情况下采样。前一轮 v16 蟑螂四窗 4/5，双类视觉提示蜘蛛 1/6。生产 `bugs.weights` 仍为空。[模型与回包核对](picf-result.json) · [原始回包](picf-wire.jsonl) · [原留出与基线](../public-bugs-independent-photos-20261123-v2/README.md)

训练总耗时约 104 秒。主机最低采样可用内存 6.05 GiB，训练进程树 RSS 最大采样 2,561 MiB，训练目录最大阶段采样约 58.9 MiB。训练与回放保护均未触发。[训练资源](resources.json) · [回放资源](picf-resources.json)

这轮验证了从数据快照到真实权重、开发验证和 PICF 推理的链路。模型未达到目标检出要求，保留在本机候选目录。本轮公开照片固定为回归基准。下一轮先固定开发集和训练评估条件，再针对小目标定位失败准备更大且按来源分组的训练集，新增独立验收样本复测。PICO 现场识别、定位和手势仍待验证。
