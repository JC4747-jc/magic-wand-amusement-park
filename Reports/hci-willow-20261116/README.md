# 打人柳四维效果：本地候选

HCI 基线：远程 pico-hci-yolo-vfx 的 HciMeetingScenario（eae26868）定义 A 黑暗风、B 枝条抽打、C 树疤呼吸、D 封印宝箱。本轮按该要求修正实际 ParkTree Fantasy 变体，共用火机手势保持不变。

| 维度 | 实现与编辑器验证 |
| --- | --- |
| A 捏合松开 | 深色树干/树冠，可再次施法还原，不切换季节 |
| B 画圈 | 五组枝条快速抽打、缓慢收回，2.4 秒后停止；不显示自然树表情或提前显示树疤 |
| C 横挥 | 显示贴合树干的虚拟树疤，Shader 亮度周期呼吸；没有平移或缩放树干 |
| D 握拳张开 | 树疤未揭示时拒绝；揭示后封印、树疤隐藏、枝条休止、宝箱盖打开；撤销恢复树疤 |

宝箱从实心黄方块改为独立底板/四壁、金属带、锁扣、内部金币及铰链盖。仅复用内置网格和共享材质，未下载外部资产。当前近景可辨认箱体和开盖，金币在箱底，所保存的侧上方镜头没有清楚展示金币；不据此宣称奖励内部细节已视觉验收。

HciSeasonTreeChecks.RunWillow 打开保存的 ParkTree，合成关节轨迹持续经生产 ProcessHandSample，逐次与火机规则一致、每次只触发一次；检测枝条偏转和回正、树疤呼吸幅度、开盖角度、封印前置、Undo/Reset、最终拟合树干和锚点不变。七张 Unity 渲染保留在 hci-willow/。实际 XR 回调和 YOLO 未参与此次测试。

同步回归四季树九图流程、原网格形变/非法风向恢复、六类内容的共用手势，以及四条件 96 次动作/139 条结果，均通过。生产识别阈值、冷却、追踪失效取消和 UI 抢占未修改。来源哈希见 sources.json。

视觉观察：黑暗风格明显但树冠仍偏暗；树疤可见，呼吸数值范围经逐帧采样验证；箱盖和内部空间可见。美术仍待优化，当前 SmallTree 网格的树种和轮廓不是完成的柳树，必须继续制作垂枝/柳叶等独立形态。该报告不把效果映射修复等同于完整打人柳交付。

资源：五项验证串行、单工作线程、有界日志及资源守卫；5 秒主机采样最低可用内存 6.385 GiB，最大单任务磁盘增长 1.96 MiB。不是连续峰值或硬盘寿命保证。未训练、未大型下载。
