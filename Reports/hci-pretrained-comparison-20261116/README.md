# 魔法乐园现有预训练权重的离线诊断

本轮使用已有 yolov8n.pt 和 yolo26n.pt，各对 41 张带候选框的公开图片运行一次 CPU 推理，共 82 次。固定输入 416、置信度 0.25、NMS IoU 0.7，单线程；完整框、置信度、权重与图片摘要见 result.json。没有新下载、训练或部署替换。运行脚本为 Tools/compare_hci_pretrained.py。

## 结果与下一步

两套权重的 COCO 类别均覆盖 Cat、Dog、chair、couch、bed、diningtable、PottedPlant；均缺少 Lighter、Tree、Cockroach、Spider、Statue、BronzeBeast。须保留并验证火机专用权重，完成其余缺失类别的数据/训练或适合的模型接入；不能仅靠 COCO 权重声称全场景识别。

## 逐图检查的缺口

已查看以下四张原分辨率候选叠框图；来源图片、候选框、叠框均按 SHA256 绑定到 visual-review.json。未改原标注，也未将其批准为训练标签。

- 2ed000d799794d71：床上两只互相遮挡、严重逆光的动物。26n 给出一个跨两只候选实例的大框，同时出现 Dog/Cat 分类；需要进一步核对物种和各实例范围。纳入分类歧义/遮挡审查，不能将两个输出解释为可靠的两个目标。
- 59987a562d6187c6：两只重叠幼猫，26n 一个大 Cat 框覆盖两只。按一对一匹配只能覆盖一个候选实例；背景另出现 bed/couch 两类预测，背景家具应复核后再判断是否误报。
- 6e86e224c7e36481：被人遮挡的沙发，26n 输出 bed。应补充有遮挡家具及床/沙发混淆样本。
- 326c062e0b66f5af：画面几乎被盆边和幼苗填满，26n 无目标输出；可见盆器局部但全物体被裁切。需要在标注规则中明确强裁切盆栽的范围，并补充真实桌面盆栽全景。

后续先完成标注范围、可见目标完整性、许可及同一拍摄/物体分组审核，再冻结训练/验证/测试划分。已查看的这些公开图不冒充新的独立测试集。PICO 设备当前未连接，仍须采集/验证真实相机域和统一手势闭环。
