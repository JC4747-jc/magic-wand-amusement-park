# mr/jc · PC 实际检测服务联通核对

使用已发布整合提交 `312fc0d5495a7cbfb5cd6c58da471078ecf78a77` 的生产 TCP 入口和路由模块，与 `mr/jc` 已有的两份权重核对哈希后，在独立目录运行真实 Windows CPU 推理。用既有火机实拍、Middlebury Playroom 和 Jadeplant、既有狗实拍文件，经本地 TCP 送入 16 份 PICF v1/v2 请求。

- 火机 5 条 v1 输入和 1 条 v2 输入均命中。Room 两条均检出椅子，Plant 两条均检出盆栽；重复输入在各自场景保持实例 ID。Pet 一条检出狗。
- Discovery 实际轮流使用了两份本地权重。Tree、Bugs、Statue 各回传一次未配置状态，检测列表为空。每条响应的场景、帧号、时间戳、尺寸及框范围均核对。
- 53 项现有自动回归通过，包括场景配置、缓存、版本解析、模型元信息、socket 重连和旧姿态服务兼容检查。首两轮只用于纠正测试脚本对置信度字段和状态文本的预期。
- 推理进程采样最低可用内存 7.79 GiB，任务进程最高 788.1 MiB。CPU 当前仅验证功能。现场头显、设备实时速度及独立训练效果仍待验。
