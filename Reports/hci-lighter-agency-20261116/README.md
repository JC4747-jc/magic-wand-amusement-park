# 火机 B：扑翼与定时咳嗽烟

补齐 HCI 火机 B 的翅膀与咳嗽烟表现。入口仍是火机原有 B 指尖画圈 → Agency → RealityEditor.TriggerAgency，不增加手型或识别阈值。保留原生命化状态与呼吸缩放，原周期低吼改由定时咳嗽声/烟团表达；独立的首次低吼不再叠加。

## 表现与资源

两翼复用一个原创折面网格：16 顶点、12 三角面（每翼渲染一次），两个渲染器与一个自有材质。膜面有折痕与凹边，绕根部受限扑动。修正非等比模型缩放压窄翅膀的问题，以真实机身高度计算各轴补偿；从原机身网格直接取得本地范围，避免世界包围盒随旋转膨胀。翅膀、眼睛和烟均不参与原机身尺寸注册，不改变追踪根位置。

B 后约 0.35 秒发出首团烟，之后每 3.2 秒一次；每次 7 粒，固定上限 14，单粒约 0.65 秒。复用现有 SoftParticle shader；双段噪声咳嗽音效为项目代码合成，固定随机种子、22050 Hz 单声道、10143 采样点，首次创建后缓存。没有音效包下载、模型训练、逐帧网格/材质创建或文件写入。

眼睛按机身范围摆到表面，修正部分模型中眼睛被机身遮挡；眼睛与咳嗽出口按主相机所在前/后侧摆放。左右视角及贴合精度仍须头显观察。当前翼膜是简化折面造型，仍需美术精修，不能将功能检查视为最终画质验收。

重复 B 重置同一表现组件并重新计时；切换到 A/C/D 或放大、Reset、对象隐藏/禁用、应用暂停会停翼、清烟并停止音效。组件销毁时释放自有网格/材质。遮挡策略本身仍由现有跟随/召唤状态负责，本批没有修改 YOLO 或追踪失效门限。

## 验证

- 专用 Play Mode 检查使用已有真实火机机身、金属罩、火轮、按压杆与通风孔网格，设置非等比作者缩放及旋转根节点。经实际 RealityEditor.ApplyDimension(B) 播放，检查扑翼幅度、首次与重复咳嗽、固定烟粒上限、前后视角眼睛位置、重复 B 资源复用、A/C/D/Reset/暂停/隐藏清理、根位置与一个 AudioSource。
- 同一运行调用 TabletopGestureChecks.Run，核对既有火机手势规则；不将直接动作调用当成真实关节或 PICO 验收。
- 原八场景回归覆盖五个实际火机目标的外观、生命化、躲闪、放大、解构、复位/中断，两个卡牌捕捉场景和 VST 配置。按原检查隔离了空间/输入组件，只证明模型与动作兼容性，不能代替原始输入启动和真实追踪测试。
- 图片为实际 Unity 相机渲染。早期方块夹具、缩放/面向修正前的图片不作为本次交付证据；旧检查日志保留在本地。

最终源码核对发现 Unity 把隔离工程 LighterDefault 材质的绿色分量从 0.84 重新序列化为 0.8399999。已备份该编辑器往返文件并恢复分支原文件；差异仅约 0.0000001，未修改主工作区材质或将此漂移作为美术改动发布。

资源统计采用每五秒采样；保留 RAM 3 GiB、C 盘 20 GiB、D 盘 25 GiB、单步磁盘增长 1 GiB、日志 16 MiB、15 分钟守卫与单 Unity/BEE worker。结果和来源摘要见 manifest.json。

本批尚未进入新 APK，也未完成真实 YOLO/PICO、真手势、双眼/遮挡、实际咳嗽听感和性能验收。HCI 其余用例缺口、美术完善、训练/模型接入目标继续进行。
